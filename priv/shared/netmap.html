Netmap

Most sites have some sort of Sitemap. A big document or list containing a bunch of links to a bunch of pages on the site. If you're looking for my sitemap, well sucks to be you, because this is not it.

But Robin, what is this then? This is a netmap. It's not a collection of pages on a site, but a collection of sites in a network. My network, to be exact. And in case you were wondering, yup, I made this up :)

Hey! If you got redirected here, that's probably because the site you were looking for doesn't exist anymore. Maybe what you're looking for is in the list below?

If you are looking for a sitemap, it's right here.

Public services

  • cipher.dupunkto.org: public Cipher instance for securely sending and receiving passphrases and API keys.
  • inv.dupunkto.org: self-hosted Invidious instance; publicly accessible but with no guarantees regarding uptime.
